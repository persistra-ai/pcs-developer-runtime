## What is PCS Developer Runtime?

**PCS Developer Runtime** is a **public evaluation runtime** for experiencing persistent cognitive substrate in long-horizon AI work.

It demonstrates three core architectural moments:
1. State lives outside the model
2. Constraints remain binding (runtime enforcement)
3. Model changes don't erase work (continuity across providers)

**Purpose:** Technical evaluation, learning, and architectural understanding

**License:** Source-available for non-commercial, non-production evaluation use

---

## What PCS Developer Runtime Is NOT

This public repository does **not** provide:

- ❌ Production deployment rights
- ❌ Commercial runtime access
- ❌ Full PCS reference implementation
- ❌ Enterprise features or support
- ❌ Conformance or certification rights
- ❌ Distributed substrate capabilities
- ❌ Advanced Context Salience Engine (CSE)
- ❌ Multi-user or team coordination features
- ❌ Hardware acceleration
- ❌ Hosted service or SaaS deployment rights

**The public runtime is intentionally bounded** to demonstrate core concepts without granting production or commercial rights.

## Frequently Asked Questions

### Can we use PCS Developer Runtime in production?

**No.** The public evaluation runtime explicitly prohibits production use. Production deployment requires a commercial license.

### Can we modify the code?

**Yes, for evaluation purposes only.** You may modify the code for internal evaluation, but redistribution and commercial use of modifications are prohibited without a commercial license.

### What's the difference between the evaluation runtime and commercial runtime?

**Evaluation runtime:** Bounded feature set, single flagship workflow, no production rights, community support

**Commercial runtime:** Full feature set, production deployment rights, enterprise features, SLA-backed support, conformance access

### How much does commercial licensing cost?

Pricing is customized based on deployment scope, user scale, feature requirements, and support level. Contact **licensing@persistra.ai** for a quote.

### Can we get an NDA to see more?

For access to the full PCS architecture, validation suites, and reference implementation under NDA, contact **research@persistra.ai** (for technical evaluation) or use the commercial inquiry form (for deployment discussions).

### Do you offer trials or POCs?

We evaluate trial and proof-of-concept requests on a case-by-case basis for qualified organizations. Submit a commercial inquiry with your use case and timeline.

### What if we just want to understand the architecture better?

Start with:
- [persistra-public](https://github.com/persistra-ai/persistra-public) - Public architectural overview
- [PCS Developer Runtime Tutorial](https://github.com/persistra-ai/pcs-developer-runtime/blob/main/TUTORIAL.md) - Hands-on experience
- [GitHub Discussions](https://github.com/persistra-ai/pcs-developer-runtime/discussions) - Community Q&A
