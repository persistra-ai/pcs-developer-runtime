# PCS Developer Runtime — Project Scope

---

## What this repository is

PCS Developer Runtime is a local evaluation runtime for experiencing persistent cognitive substrate in long-horizon AI work.

It exists to demonstrate one core architectural shift:

**Authoritative project state can live outside the model and persist across sessions, constraints, decisions, vision, and model changes.**

This repository is intentionally focused on a single flagship workflow:

**Persistent Project Assistant**

That workflow demonstrates:
- persistent project decisions,
- persistent project constraints,
- persistent vision / mission context,
- session resumption,
- inspectable decision trace,
- and model-agnostic continuity.

This repository is meant to make the substrate difference understandable and testable in a bounded local environment.

## Included in this public runtime

This repository includes a minimal local runtime sufficient to demonstrate:
- project initialization,
- local persistent project state,
- project decisions,
- project constraints,
- project vision,
- runtime enforcement of active constraints,
- session continuity metadata,
- inspectable decision trace,
- and bounded assistant behavior over substrate-presented project state.

Depending on the configured build, it may also include limited multi-model support so users can experience model swap continuity.
